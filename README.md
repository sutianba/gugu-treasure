# 咕咕冒险记 · Gugu Adventure

> 城市鸽子收集宝物的三消解压小游戏 — 单文件 HTML 原型

一只圆滚滚的鸽子"咕咕"在城市各个角落拾宝——点击叠放的宝物方块送入底部队列，集齐 3 个相同宝物即可消除。全部消完即过关。

## 🎮 在线试玩

- **GitHub Pages**：<https://sutianba.github.io/gugu-treasure/>
- **Gitee 仓库**：<https://gitee.com/shyKINGDOM/gugu-adventure>

任意浏览器打开即可，无需安装。

## ✨ 当前特性

### 核心玩法
- **堆叠三消**：多层方块遮挡，只有最上层可点击 → 7 格队列 → 集齐 3 个自动消除
- **20 个关卡**：中央公园 → 海边码头，方块数 18→51 平滑递增，宝物种类 4→8 逐步引入
- **12 种宝物**：🪙🔴🪶🍬🌰🎲🔑💎🌿🧿🍞🧶
- **道具系统**：撤回 ×3 / 洗牌 ×1 / 透视 ×1 / 重来

### 特色机制
- **鸽子情绪反馈**：开心 / 紧张 / 慌张 / 兴奋 / 难过 / 胜利，6 种表情实时切换
- **大橘捣乱**：橘猫随机盖住方块，连消 2 次赶走（第 14 关起出现）
- **风向特效**：叶子飘过的氛围动画（第 11 关起出现）
- **WebAudio 音效**：拾取 / 消除 / 连消 / 过关 / 大橘 / 巢穴，全部实时合成

### 巢穴装饰系统 ⭐
- **收集册**：展示已收集的 12 种宝物及数量
- **自由装饰**：从托盘拖拽宝物到巢穴画布，任意位置摆放（支持触屏拖拽）
- **5 套主题**：原木巢 / 春日花园 / 夕阳天台 / 夜色屋顶 / 海边码头
- **自动存档**：摆放位置、主题选择实时保存，刷新不丢

### 社交与挑战 ⭐
- **战报卡片**：过关/失败后 canvas 生成精美战报图，含得分、用时、最高连消、本局最稀有宝物，可一键保存图片
- **挑战好友**：生成带种子的挑战链接，朋友点开玩**同一关卡**（牌局逐格一致），比分高低
- **每日挑战**：按日期生成固定种子，全服同一关
- **排行榜**：云端榜单，填昵称即可上榜，同一昵称同一关卡只保留最高分

### 关卡一致性（种子化）
挑战链接 / 每日挑战下，牌局由种子决定：方块位置、宝物种类、大橘出现时机全部可复现。
同一链接在任何设备、任何时间打开，都是**完全一样的一局**；自由模式仍为随机牌局。

### 数据持久化
- 关卡进度、总分、巢穴收集、装饰摆放、主题选择全部写入 `localStorage`
- 手机端 `pagehide` / `beforeunload` 自动兜底保存
- 昵称同样本地保存，上榜无需重复输入

### 云端（WorkBuddy 云服务）
排行榜数据存放在 WorkBuddy 托管的云数据库（PostgreSQL + RLS），前端只持有可公开的
`endpoint` + `publishableKey`，无任何密钥泄露风险。榜单按 `challenge_key` 分组，
挑战链接与每日挑战各自独立成榜。

### 移动端适配
- viewport 配置 + 38-40px 触控热区 + Pointer Events 拖拽
- 禁用长按菜单、双击缩放

### 手机桌面安装（PWA）⭐
- **添加到主屏幕**：手机浏览器打开后，通过「添加到主屏幕」安装成桌面图标，全屏独立窗口运行，和 App 体验一致
- **离线可玩**：Service Worker 预缓存核心资源，断网也能继续闯关（排行榜联网时恢复）
- **iOS 安装引导**：iPhone 首次访问自动提示分享→添加到主屏幕的步骤
- 云端接口不走缓存，排行榜数据始终实时

## 📁 项目结构

```
gugu-adventure/
├── index.html            # 游戏主文件（HTML+CSS+JS+SVG 单文件）
├── manifest.webmanifest  # PWA 应用清单（名称/图标/独立窗口）
├── sw.js                 # Service Worker（离线缓存）
├── icon-*.png            # 应用图标（192/512/maskable/apple-touch/favicon）
├── README.md             # 本文件
└── .gitignore
```

单目录静态站点，无构建步骤、无 npm 依赖，任意静态托管可直接部署。

## 🛠 本地运行

需要 Python 3 或 Node.js 任一即可：

```bash
# Python 3
python -m http.server 8000

# Node.js
npx serve .
```

浏览器访问 `http://localhost:8000/`。

**注意**：直接双击 `index.html`（`file://` 协议）会导致 AudioContext 在部分浏览器被禁用，请通过 HTTP 协议访问。

### 挑战链接格式

```
?challenge=<种子数字>   好友挑战，同一关卡
?daily=1                每日挑战，按日期生成
```

### 安装到手机桌面

手机浏览器（iOS Safari / Android Chrome）访问游戏链接后：

- **iPhone**：点底部「分享」→「添加到主屏幕」
- **Android**：菜单 →「添加到主屏幕」或「安装应用」

之后从桌面图标进入即全屏运行，可离线玩主线关卡。
